# AURA SEATING — Event Seating Studio

A standalone trilingual event seating planner for GitHub Pages. Open `index.html` directly or use VS Code Live Server. No backend required.

Features: 15 tables in 5 × 3 layout; editable event details; guests and CSV import; table capacities; guest check-in and removal; enlarged mobile guest and table panels; seating rules and smart assignment; drag-and-drop tables and guests; zoom and fit; review and CSV/JSON export; localStorage.

**Note:** This is an interactive HTML/CSS approximation of the approved concept image, not a pixel-for-pixel photorealistic 3D render. The venue is drawn using CSS so it remains interactive. The demo guest names are illustrative. Existing SEAT SMART localStorage is not overwritten because this edition uses its own storage key.
