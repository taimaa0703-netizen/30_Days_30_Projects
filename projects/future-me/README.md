# FUTURE ME — Israeli High School Edition

Open `index.html` in VS Code Live Server, or deploy this folder to GitHub Pages. No build step, accounts, or API keys required.

Includes Hebrew, locally natural Arabic for Arab high-school students in Israel, and English. The site preserves a consistent left-to-right application layout while each localized content region uses its proper reading direction, keeping sentence punctuation in the right place. The supplied Future Me logo is included in `assets/future-me-logo.png`.

Features: interest selection, six interactive career tasks, editable Bagrut subject/unit/mark tracker, student profile, higher-education directory and filters, verified official degree links for selected programs (other links explicitly lead to official institution homepages), favorites, compare up to three programs, flexible roadmap, downloadable plain-text Future Passport, and local persistence.

Privacy: All inputs are stored in localStorage on the device. Do not enter minors' identifiable information on shared computers. Clear browser storage to remove saved data.

Accuracy: This tool does NOT determine formal Bagrut eligibility, admission probabilities or degree accreditation. Requirements vary by institution and year. The official website linked to each program is the ultimate source of current details. Where no exact program URL is verified, the institution homepage is linked and labeled accordingly. Universities and colleges are sampled from official Israeli higher-education listings. The directory is curated, not exhaustive.

No stars or decorative emoji are used inside the site.
