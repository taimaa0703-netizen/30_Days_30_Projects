# BUSLY — Day 21 / 30
Interactive trip passenger counting and bus seating planner.

Open `index.html` in a browser or use VS Code Live Server. No backend, API keys or build tools required.

Features: illustrated bus, selectable 2+2 seating plan, configurable rows, passenger list and seat assignments, name-based boarding confirmations, separate +1/+2 walk-through counter, return trip reset, CSV import/export, localStorage persistence, Arabic/Hebrew/English UI.

Important: The manual counter does not verify identities. Confirm each passenger by name and physically check the bus before departure. Data is stored only in the browser on the current device. For privacy, avoid entering sensitive information.

Fonts use Google Fonts when online; system fonts are used offline.
