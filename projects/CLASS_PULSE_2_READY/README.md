# CLASS PULSE 2.0 — Teacher Workspace / Progress Circle

## Run

Extract the ZIP. Open `index.html` in VS Code Live Server or deploy the folder as-is on GitHub Pages. No login or server required for the local demo. Use fictional student records only.

## What was preserved

The existing `index.html` (including its original student, attendance, assignments, insights, CSV export screens and data storage), `csv-import.js`, `classpulse-upgrade.css`, and the original `classpulse-upgrade.js` extension remain the foundation. The new design and workflows are incremental additions. The existing localStorage keys `classpulse_data` and `classpulse_upgrade_v1` are **not replaced or cleared**.

## CLASS PULSE 2.0 features

- Progress Circle identity and a deep-teal/mint Teacher Workspace with line-icon sidebar.
- The signed-in username is reused in the dashboard greeting; its teacher title is localized, editing the greeting updates the same saved name, and existing sessions sign in once to link the username.
- Dashboard home: editable teacher greeting with animated illustration, four quick actions (manage classes, attendance, add task, quick assessment), today's tasks checklist (auto-checked from real data, manual ticks saved per day) and an animated assessment-completion ring fixed at 87% to match the approved design (not computed from data). "Add task" opens the new-assignment form titled "Add task".
- Class analytics donut shows the selected subject name in its center.
- Report Studio grade distribution can use any single subject or all subjects; the selected subject name appears in the donut center. Class details show the first three subjects with icons.
- Report Studio can highlight the three highest student averages across active subjects for the selected term; first place is centered in the celebratory ranking, and individual parent reports never expose class rankings.
- Hebrew and Arabic full-page right-to-left layout with sidebar on the right; English left-to-right with sidebar on the left. Arabic subject name is `حساب` instead of `رياضيات`.
- Browser back/forward and reload-safe hash-based navigation (e.g. `#/classes`, `#/studentProfile/1`). Class and semester selections persist locally.
- Existing create-class and local join-code demo; semester management including add/edit/duplicate structure without duplicating grades.
- Student profiles and custom subjects preserved; quick assessment for whole class with local autosave drafts and CSV grade template/import. Missing-grade overview.
- Global search for students, classes and saved report drafts.
- Report Studio four-stage wizard: audience, content and order, formatting, preview, save a report preset, presentation mode with Esc/prev/next, a redesigned visual slide deck, native editable PowerPoint charts for mastery, grade distribution and semester trends, PDF via native Print > Save as PDF with A4 portrait/landscape. Section selection persists, and unavailable reorder/add controls are disabled.
- Report Library saves editable report configurations and audience filters locally; does not upload or synchronize reports.

## Notes about exports

PDF export uses the browser's print dialog. In Chrome, select **Save as PDF**. You can select portrait or landscape within Report Studio; print settings in Chrome may override page size and orientation. Verify the preview before saving. PPTX is generated by the bundled `vendor/pptxgen.min.js` and must be viewed in PowerPoint, Keynote, or LibreOffice Impress. Chart appearance and text wrap can differ slightly between programs. Visual browser tests covered the main screens, report wizard and presentation mode; automated file-download testing was not completed in this environment.

## Data scope and privacy

This is a **local, offline-first prototype**. Teacher codes and permissions are simulated in browser storage. They are **not secure login or cross-device collaboration**. Do not put names, grades, behavioral comments or personally identifying information of real children into the published demo. A real school deployment requires authenticated users, server-enforced role/class permissions, a secure database, audit logs, and institutional privacy review.
