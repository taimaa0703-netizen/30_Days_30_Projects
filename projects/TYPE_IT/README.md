# TYPE IT. — a social typography studio

**Day 11 — 30 Days • 30 Projects**

A fully client-side typography and quote-post design editor. No Node.js, API keys, or login needed.

## How to run
1. Open `index.html` directly in Chrome, Safari, Edge, or through VS Code Live Server.
2. Type your copy, try templates, drag text on the poster, adjust fonts/colors/format, and export PNG.
3. Deploy the three files `index.html`, `style.css`, and `script.js` to GitHub Pages.

## Features
- Post (1:1), portrait (4:5), story (9:16), wide (16:9) native-resolution export
- Presets in pink, cherry, matcha, lime, editorial, midnight, lavender, and blue
- Arabic, Hebrew, and English input with automatic text direction and direction override
- Multiple text layers, click to select, drag to move
- Font, font size, line-height, alignment, accent and text colors
- Background uploads, responsive photo positioning, opacity overlay, decorative effects
- Undo/redo for most editing operations; save/restore local design; PNG export
- Browser-local design state: user-generated photos are not sent anywhere

Fonts load from Google Fonts when online. When offline, system fonts are used as fallbacks; available fonts affect text layout/export. The canvas exporter exports text and images directly from the browser.
