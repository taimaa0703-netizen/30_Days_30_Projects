# CLASS PULSE — Classroom Intelligence

Open index.html through VS Code Live Server. Use English, Hebrew or Arabic from the selector.
Features: editable student profiles and subject mastery, attendance by date, assignments and completion, class heatmap, targeted teacher suggestions, CSV import/export, local persistent data, reset demo.
Import a UTF-8 CSV using the exported columns `Student,Mathematics,Reading,Science` (Hebrew and Arabic column names are supported too). Matching student names update their subject scores; new names are added. Other students and their attendance/assignment records stay unchanged. Scores must be between 0 and 100.
This is a local prototype: no multi-device sync, no authentication, and no handling of real student personal data. Use fictional profiles until a secure backend and appropriate access permissions and privacy safeguards are implemented.
