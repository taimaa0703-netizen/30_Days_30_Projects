# CLASS PULSE — Classroom Intelligence

Open index.html through VS Code Live Server. Use English, Hebrew or Arabic from the selector.
Features: editable student profiles and subject mastery, attendance by date, assignments and completion, class heatmap, targeted teacher suggestions, CSV export, local persistent data, reset demo.
This is a local prototype: no multi-device sync, no authentication, and no handling of real student personal data. Use fictional profiles until a secure backend and appropriate access permissions and privacy safeguards are implemented.
